// 01 — 范式

VIBE MOTION

一种内容生产范式

“Vibe Motion” 是 Higgsfield 于 2026 年 1–2 月发布同名产品时造出并带火的概念：将 Agent 作为超级入口，通过自然语言生产出专业级的动效视频。本质上是一次内容生产流程范式的定义——与 Karpathy 2025 年提出的 “vibe coding” 一脉相承。

VIDEO AS CODE

开源框架已为 Agent 适配

市面上出现了一批开源视频框架：Remotion（React 派，~50.9K★，上线首周 1300 万曝光、2.5 万安装，skills.sh 全站第三）与 HyperFrames（HTML 派，~29.7K★）。它们均针对 Agent 交互范式做了适配，押注同一共识——用自然语言驱动 Agent 生成视频（视频本质就是一系列结构化帧的序列）。
